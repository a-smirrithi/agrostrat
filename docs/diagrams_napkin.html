Figure 4.5: Sequence Diagram of Coordinate Ingestion & Decision Flow
Chronological 8-step workflow from user coordinate selection to explainable advisory display
1
User / Client UI
Farmer selects preset (e.g. Kanchipuram) or submits custom GPS coordinates.
2
Express Router
Client issues HTTP POST /api/verify with { latitude, longitude, cropType }.
3
Land Classifier
Queries Chennai urban boundary mask and Sentinel-2 NDVI/NDBI indices to verify land type.
4
Weather Gateway
Fetches root-zone soil moisture (0-7cm, 7-28cm), humidity, wind, and rain from Open-Meteo.
5
AgroEngine
Computes FAO-56 Penman-Monteith ET₀, water deficit, and Rice Blast humidity dwell index.
6
Note Dispatcher
Synthesizes 3 action cards with plain-language 'Note' badges citing exact telemetry values.
7
MongoDB Atlas
Stores immutable assessment history document with coordinates, classification, and advice.
8
React Dashboard
HTTP 200 JSON payload parsed; UI renders green/red status cards and today's action plan.
